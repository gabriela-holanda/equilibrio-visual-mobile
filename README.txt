EQUILÍBRIO — versão GitHub Pages

Esta versão foi feita para ser extremamente simples:
- existe apenas UM arquivo: index.html
- não precisa de Node, banco de dados, Render ou backend
- funciona no GitHub Pages
- os dados do protótipo ficam no localStorage do navegador
- é uma versão demonstrativa, não um sistema de autenticação real

COMO PUBLICAR:
1. Abra seu repositório do GitHub.
2. Entre em Add file > Upload files.
3. Envie APENAS o arquivo index.html desta pasta.
4. Se já existir um index.html, substitua o antigo.
5. Faça Commit changes.
6. Em Settings > Pages, deixe:
   Deploy from a branch
   Branch: main
   Folder: / (root)
7. Aguarde alguns minutos e abra seu endereço do GitHub Pages.

IMPORTANTE:
O projeto foi pensado para funcionar como protótipo mobile. No celular, ele usa navegação inferior e layout responsivo.
